AgentOS 1.0.4

- Fixed: logging in on the local console (a monitor, or a VM's VNC console) always failed. Debian 13 no longer installs the `login` program automatically, and the image didn't add it, so the console went straight back to `login:` after the user name. Boxes installed from 1.0.0 to 1.0.3 can't log in at the console to update. Update over SSH or the web UI if either is set up; otherwise reinstall from the 1.0.4 installer.
- With LAN access to the web UI on, typing just the box's address into a browser (`http://<IP>`) now redirects to `https://<IP>`. Before, the page just hung.
