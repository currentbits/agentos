AgentOS 1.0.1

- Grok API keys now work: AgentOS stores the key as XAI_API_KEY, the name Grok reads (1.0.0 used GROK_CODE_XAI_API_KEY, which Grok never saw). An existing key is renamed automatically on update.
- Stopping a desktop now takes at most 10 seconds (it could hang for up to 90).
- Debian updates no longer fail when the AgentOS update repository is unreachable.
- Docs: signing in to Claude Code, Codex, opencode and Grok with a subscription instead of an API key.
