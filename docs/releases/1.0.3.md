AgentOS 1.0.3

- Web UI on your local network (opt-in): turn on "web UI on the local network" in the installer, or later with `sudo agentos-config set AGENTOS_WEB_LAN 1 && sudo agentos-config apply`, then open https://<the box's IP>. Log in with the agent password. The certificate is self-signed; check its fingerprint against the one on the console. Tailscale access keeps working as before.
- The console always shows how to reach the web UI (or how to turn it on).
- LAN logins are rate-limited, sessions expire after 12 hours idle, and changing the agent password with agentos-config logs every LAN session out.
