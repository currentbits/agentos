AgentOS 1.0.0

The first public release of AgentOS: a headless Debian 13 machine for AI coding agents.

- Agents: Claude Code, Codex, opencode and Grok preinstalled, with Rust, Node, Bun, Python, Docker and Playwright.
- Desktops for computer use: on-demand XFCE desktops that agents drive through the agentos-computer MCP server, viewable in the browser.
- Web UI over Tailscale: sessions, terminals, desktops, CI, settings, system status and updates, behind a Tailscale identity allowlist.
- Solenta: run Solenta 0.27 or later headless on the box (Remote Connections), or use the box as a worker host from Solenta on your Mac.
- Built-in CI: agentos-ci runs .agentos/ci.yml, GitHub workflows (via act) or auto-detected test suites locally; push to agent@<box>:git/<name>.git to run CI on push; agents use the ci_run / ci_wait MCP tools.
- Updates: the box checks this signed apt repository daily and shows when a new release is available on the web UI, the console and at SSH login. Click Update (or run agentos-update); agentos-update --rollback goes back. Nothing installs on its own.
- Install: USB or virtual CD installer with Secure Boot, or the VM images.
